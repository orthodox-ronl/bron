# Ideeën-backlog

Deze map bevat **onsamenhangende ontwikkelideeën** — kort beschreven, met status, als
basis voor latere realisatie. Net als [andere plannen](../README.md) **niet normatief**.

Bij een nieuw idee: kort beoordelen of het zinvol is en wat we **nu al** moeten organiseren
om implementatie later niet te blokkeren.

## Statuslegenda

| Status          | Betekenis                                              |
| --------------- | ------------------------------------------------------ |
| `idee`          | Beschreven, nog niet goedgekeurd voor implementatie    |
| `voorbereid`    | Randvoorwaarden geregeld; implementatie kan starten    |
| `gepland`       | Ontwerpkeuzes vast; in roadmap of PR-queue             |
| `in-uitvoering` | Actieve ontwikkeling                                   |
| `gerealiseerd`  | Afgerond; link naar spec of PR                          |
| `afgewezen`     | Bewust niet doen; korte reden in het idee-document     |
