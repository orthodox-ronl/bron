# Zangstuk

Een **zangstuk** is een liturgisch-muzikaal geheel met een stabiele
`zangstuk-id`, waaronder nul of meer varianten bestaan.

Zie ook: [Terminologie, paragraaf 5](../specs/terminologie.md#5-zangstuk).
